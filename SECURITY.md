# Security Policy

## Reporting Security Issues
We take smart contract and protocol security seriously. If you discover a vulnerability or security concern, please disclose it responsibly:

- **Email:** `security@omnidreams.xyz`
- **PGP Key:** Available upon request

Please allow reasonable time for remediation before any public disclosure.

## Scope
- `contracts/OmniDreamsToken.sol`
- `contracts/FeeEscrowDistributor.sol`
- Bonding curve mathematical invariants and FeeEscrow routing logic.
